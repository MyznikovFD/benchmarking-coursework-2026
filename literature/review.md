# Обзор литературы и источников

---

## Книги

### 1. Automatic Nonuniform Random Variate Generation

**Библиографические данные.** Hörmann W., Leydold J., Derflinger G.
Automatic Nonuniform Random Variate Generation. — Springer,
Statistics and Computing, 2004.

**Обзор.** Монография систематизирует методы автоматической генерации
случайных величин из непрерывных и дискретных распределений. Основное
внимание уделено универсальным алгоритмам, не требующим ручной
настройки под конкретное распределение: методу инверсии функции
распределения, табличным методам, методам отклонения (rejection)
с автоматическим построением огибающих. Отдельные главы посвящены
численной устойчивости обратной функции распределения (PPF), работе
в хвостах и обработке граничных случаев. Книга возникла из проекта
UNU.RAN и лежит в основе его архитектуры.

**Зачем в работе.** Источник обосновывает выбор операций и метрик
для сценариев сэмплирования и PPF: здесь описаны типовые
проблемы численной устойчивости, из-за которых методы могут
расходиться. Задаёт терминологию и постановку задачи
сравнения методов генерации.

---

### 2. Non-Uniform Random Variate Generation

**Библиографические данные.** Devroye L. Non-Uniform Random Variate
Generation. — New York: Springer, 1986.

**Обзор.** Классическая монография, охватывающая практически все
методы генерации случайных величин, известные на момент публикации:
инверсию, композицию, отклонение, специальные алгоритмы для
конкретных семейств распределений. Книга считается справочником,
на который ссылается большинство последующих работ по теме. Многие
алгоритмы, используемые в современных библиотеках (включая UNU.RAN
и SciPy), восходят именно к ней.

**Зачем в работе.** Служит фундаментом
для сравнения методов генерации. Помогает понять, какие алгоритмы
имеют разные асимптотические профили и почему разделение
prepare/fit и evaluate имеет смысл.

## Стандарты и эталонные данные

### 3. NIST Statistical Reference Datasets

**Библиографические данные.** NIST Statistical Reference Datasets. —
URL: https://www.itl.nist.gov/div898/strd/

**Обзор.** Набор сертифицированных эталонных значений, вычисленных
с высокой точностью для типовых статистических задач: линейная
регрессия, дисперсионный анализ, нелинейная регрессия, проверка
распределений. Для каждого набора опубликованы как результаты
(с указанием числа верных значащих цифр), так и метод их получения.
Широко используется для валидации численного и статистического
программного обеспечения.

**Зачем в работе.** Задаёт стандарт качества эталонных значений.

## Документация библиотек и инструментов

### 4. SciPy: scipy.stats

**Библиографические данные.** SciPy documentation: scipy.stats. —
URL: https://docs.scipy.org/doc/scipy/reference/stats.html

**Обзор.** Официальная документация модуля `scipy.stats`, входящего
в SciPy. Описывает API для работы с вероятностными распределениями:
`pdf`, `cdf`, `ppf`, `rvs`, моменты, статистические тесты. Для каждого
распределения задокументированы параметризация, носитель, граничные
случаи. SciPy — де-факто эталонная библиотека в научных вычислениях
на Python.

**Зачем в работе.** Основной кандидат для внешнего сравнения.
Документация нужна, чтобы корректно сопоставить операции и параметры
между PySATL Core и SciPy, а также зафиксировать расхождения
в соглашениях о носителе и граничном поведении.

---

### 5. UNU.RAN User Manual

**Библиографические данные.** Leydold J., Hörmann W., Janka E.,
Tirler G. UNU.RAN User Manual. —
URL: https://statmath.wu.ac.at/unuran/

**Обзор.** Руководство по библиотеке UNU.RAN (Universal Non-Uniform
RANdom number generators), предназначенной для автоматической
генерации случайных величин из произвольных непрерывных и дискретных
распределений. Описывает доступные методы (инверсия, табличные методы,
методы отклонения), их параметры и области применимости. UNU.RAN
используется в статистических средах и встраивается в другие
библиотеки.

**Зачем в работе.** Второй кандидат для внешнего сравнения, помимо
SciPy. Позволяет сопоставить не только результаты, но и подходы
к организации методов генерации.

---

### 6. mpmath

**Библиографические данные.** Johansson F. et al. mpmath: a Python
library for arbitrary-precision floating-point arithmetic. —
URL: https://mpmath.org/

**Обзор.** Библиотека для вычислений с плавающей точкой произвольной
точности на Python. Позволяет получать значения функций распределения
с точностью, недостижимой для `float64`. Используется как эталон
в задачах, где аналитическая формула неудобна, а стандартная двойная
точность недостаточна для проверки.

**Зачем в работе.** Кандидат в поставщики высокоточных эталонов.
Позволяет отделить расхождения, вызванные тестируемой реализацией,
от расхождений, вызванных ограничениями двойной точности.

---

### 7. GitHub Actions: workflow_dispatch

**Библиографические данные.** GitHub Actions: workflow_dispatch
event. — URL: https://docs.github.com/en/actions

**Обзор.** Документация GitHub Actions, описывающая запуск workflow
по событию `workflow_dispatch`. Событие позволяет запускать workflow
вручную через веб-интерфейс или API, что отличает его от запуска
по push или pull request. Поддерживает передачу входных параметров
при запуске.

**Зачем в работе.** Обосновывает модель CI: полные наборы бенчмарков
не должны запускаться на каждом pull request, а запускаются вручную
для выбранных сценариев. `workflow_dispatch` — техническая основа
такого запуска.

## Репозитории проекта

### 8. PySATL Core

**Библиографические данные.** PySATL Core. —
URL: https://github.com/PySATL/pysatl-core

**Обзор.** Основной репозиторий PySATL Core — библиотеки для
статистического анализа. Содержит модуль `families` с параметрическими
семействами распределений, публичные интерфейсы для работы
с характеристиками распределений и преобразованиями. Фреймворк
бенчмаркинга использует исключительно публичные API этого репозитория.

**Зачем в работе.** Предметная область: методы, которые подлежат
сравнению, реализованы здесь.

performance and numerical quality» в репозитории PySATL Core. —
URL: https://github.com/PySATL/pysatl-core/issues/124

**Зачем в работе.** Используется для формулирования цели, задач
и критериев успеха.
