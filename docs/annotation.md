# Аннотация

**Тема работы:** Базовая реализация фреймворка для бенчмаркинга
производительности и численного качества методов PySATL Core.

---

PySATL Core содержит несколько реализаций для одних и тех же
характеристик распределения, преобразования или генерации выборки.
Модульные тесты подтверждают корректность контрактов, но не дают ответа
о практическом качестве: такие реализации могут различаться по времени
выполнения, потреблению памяти, численной точности и устойчивости
вблизи хвостов, границ и особенностей плотности. Отсутствие единой
методологии сравнения затрудняет обоснованный выбор метода и
воспроизводимое сопоставление с внешними библиотеками.

Цель работы — разработать и реализовать базовую версию настраиваемого
воспроизводимого фреймворка для сравнительного анализа. Фреймворк
решает две задачи: внутреннее сравнение нескольких реализаций
PySATL Core для одной и той же операции и внешнее сравнение
PySATL Core с независимыми библиотеками (в первую очередь SciPy)
при эквивалентности функциональности и совместимости лицензий.
Фреймворк использует публичные интерфейсы PySATL Core и не затрагивает
его внутреннее устройство.

Каждый сценарий бенчмарка явно описывает распределение, операцию,
оцениваемый метод, входные данные, эталон, политику измерений и
метаданные воспроизводимости. Отдельное внимание уделяется разделению
времени подготовки (prepare/fit) и повторной оценки (evaluate), явной
обработке несопоставимых случаев и документированию накладных расходов
адаптеров. Численное качество оценивается через логарифмическую
относительную ошибку (LRE), равномерную норму, поточечные ошибки и
квантильные метрики; качество непрерывного сэмплирования — через
преобразование интегральной вероятности с диагностиками Uniform(0, 1).

Работа рассчитана на учебный год. В первую половину года выполняются
контракты сценария, адаптера, эталона, измерения и результата,
начальный раннер с сохранением сырых данных и генерацией отчётов,
набор сценариев Core-vs-Core для выбранных распределений и операций,
базовые метрики численного качества и адаптер SciPy с первыми
сопоставимыми сценариями. Во вторую половину года реализуются
сценарии сэмплирования, раздельные тайминги подготовки и оценки,
контракт подключаемого измерения памяти, ручной CI workflow с
артефактами и опциональная публикация отчётов.

Работа даёт воспроизводимые свидетельства о численном качестве и
использовании ресурсов реализаций PySATL Core, пригодные для
обоснования решений по оптимизации.
